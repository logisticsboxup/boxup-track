# BoxUp company tracking

https://logisticsboxup.github.io/boxup-track/

Each Sender Company in the BoxUp Label Log gets its own 9-character access code
(tab **Client Codes** in the Label Log sheet, made automatically). A company signs in
with its code and sees only its own orders, with live status, shipment progress and POD.

- To give a company access: copy its code from the Client Codes tab and send it with the link.
- To change a code: type a new 9-character code in the Access Code column.
- To stop a company: set Active to No.
- Contact Name / Role / Phone / WhatsApp / Email on that row replace the default BoxUp contact in Support.
